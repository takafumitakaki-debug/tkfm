# 税金計算ツール

イバノのサイト制作（`claude/ivano-corporate-site-ia-htsmmj` ブランチ）とは無関係の、個人用ツール置き場。このブランチはイバノの履歴を含まない独立ブランチ。

## tax/index.html — ふるさと納税・法人オーナー節税シミュレーター

令和8年分（2026年の所得）の税制で計算する。ビルド不要で、ブラウザで開けば動く。

- **ふるさと納税の上限額**：給与・家族構成・iDeCo・保険料などから、自己負担2,000円で収まる寄附額を出す。寄附予定額を入れると自己負担も確認できる
- **サラリーマン＋法人の節税**：役員報酬（月額）ごとに「本人の手取り＋法人の税引後利益」を計算し、最大になる額を出す。小規模企業共済・経営セーフティ共済・借上げ社宅・出張日当の効果も比べられる

公開版：https://claude.ai/artifact/UGNznNVq7cMYfLgXiHmp8n

結果は目安。計算の前提（社保は協会けんぽ東京の料率で概算、法人は中小法人・東京都の標準税率など）はページ下部に記載。
