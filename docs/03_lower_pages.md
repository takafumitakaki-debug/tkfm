## 共通レイアウト（01〜05 の章ページ）

すべての章ページは同じ骨格で作る。章ごとに読み心地を揃え、「1冊の本の別の章」に見せるため。

```
┌ HEADER ─────────────────────────────┐
│ 章扉（PAGE HERO）                      │
│   章番号「01」／章名「理念」／英字「ABOUT」  │
│   この章が答える問い（1行）               │
│   横長写真1枚                           │
├─────────────────────────────────────┤
│ 章内ナビ（ページ内アンカー）              │
├─────────────────────────────────────┤
│ 本文セクション群                         │
├─────────────────────────────────────┤
│ 次の章へ（NEXT CHAPTER）                 │
│   「02 フィロソフィ ― 理念を、毎日の仕事でどう形にしているか。→」│
├─────────────────────────────────────┤
│ 共通お問い合わせブロック ／ FOOTER          │
└─────────────────────────────────────┘
```

表の見方：**目的**＝そのセクションで伝えること／**内容**＝見出し・原稿・構成要素／**写真**＝必要なビジュアル／**CTA**＝ボタンとリンク先

## 03 事業 BUSINESS `/business/`

**ページの役割**：理念とフィロソフィを、実際の仕事としてどう実現しているかを示す。

**読後に理解してほしいこと**：イバノは「食材を売る会社」ではなく、世界と沖縄の食材を選び、運び、沖縄のホテル・飲食店・家庭の食の場面を毎日成り立たせている会社。
