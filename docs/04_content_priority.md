# ④ コンテンツの優先順位

判断基準：

- **必須**：公開時点で無いと「理念 → フィロソフィ → 事業 → 人 → 地域」の物語が成立しない、または企業サイトとしての信頼が欠けるもの
- **あると良い**：物語の説得力を大きく高めるもの。公開時に間に合えば入れる
- **今後追加**：公開後の運用で育てるもの。構造（枠）だけは最初から用意しておく

## あると良い（公開時に間に合えば）

| ページ | コンテンツ | 効果 |
|---|---|---|
| 01 理念 | 理念に込めた意味（キーワード解説） | 理念が「額縁の言葉」で終わらず、現場の言葉になる |
| 02 フィロソフィ | 「現場では」エピソード（各項目） | 抽象的な考え方を具体的な行動で証明できる |
| 02 フィロソフィ | フィロソフィが表れる日常（3〜4場面） | 取引先が「任せられる理由」を実感できる |
| 03 事業 | 数字で見るイバノ（取引先数・アイテム数等） | 規模と信頼を一目で伝える |
| 03 事業 | 担当者の言葉／取引先様の声 | 事業紹介に人の温度が入る |
| 03 事業 | 品質・物流への取り組み | 業務用取引の判断材料 |
| 03 事業 | PB商品のラインナップ | 「つくる側」の顔を見せられる |
| 04 人 | 1日の仕事（2職種） | 仕事を具体的にイメージできる |
| 04 人 | 社内文化の具体例（誕生日カード等） | イバノらしさを最も端的に伝えられる素材 |
| 05 地域 | 県内生産者との関係 | 「沖縄の食」を食材側からも語れる |
| 05 地域 | これから目指すこと | 物語を未来へつなげる |
| RECRUIT | 仕事を知る（職種別ページ） | ミスマッチ防止 |
| RECRUIT | 働く環境（数字・制度） | 応募判断の材料 |
| TOP | FV のループ動画 | 現場の空気感を最も強く伝えられる |
