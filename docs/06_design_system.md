# ⑥ UI/UX デザインシステム

実装：`site/src/styles/tokens.css`（トークン）／`site/src/styles/base.css`（共通クラス）／`site/src/components/`（部品）
一覧ページ：`/styleguide/`（noindex。制作・運用担当向け）

---

## 1. デザインの原則

情報設計（docs/00〜05）の方針を、見た目のルールに翻訳したもの。迷ったらここに戻る。

| # | 原則 | 具体的なルール |
|---|---|---|
| 1 | **1冊の本として読ませる** | 章番号（01〜05）を全ページで共通に使う。章ページは「章扉 → 章内ナビ → 本文 → 次の章へ」の骨格を崩さない |
| 2 | **紙とインク、アクセントは1色** | 背景は温かみのある白、文字は墨色。赤（`--c-accent`）は CTA・章番号・強調にだけ使い、面で多用しない |
| 3 | **写真の主役は人の手と現場** | 物撮り・記号的な沖縄（海・シーサー・赤瓦）は使わない。写真がない間は撮影指示入りの枠を出す |
| 4 | **情報は余白の中に置く** | 数字・沿革・会社概要は罫線だけの表組みで淡々と。影・グラデーション・角丸で信頼感を作らない |
| 5 | **原稿がない所は創作しない** | 【…】で仮置きし、青い破線で可視化。公開前チェックで残数をゼロにする |

## 2. トークン

### 色

| トークン | 値 | 用途 |
|---|---|---|
| `--c-paper` | #f7f4ef | ページ背景 |
| `--c-paper-2` | #efe9e0 | 交互セクション（`.section--alt`） |
| `--c-card` | #ffffff | カード・入力欄 |
| `--c-ink` / `--c-ink-2` / `--c-ink-3` | #1d1a17 / #5b544c / #70675d | 本文／補足／キャプション・英字ラベル |
| `--c-line` | #dcd4c8 | 罫線 |
| `--c-accent` | #9b3320 | CTA・章番号・強調（熟成肉の赤） |
| `--c-deep` | #1f2622 | 暗いセクション（次の章へ・結び・フッター・採用ヘッダー） |
| `--c-ph` / `--c-check` | #1f5fbf / #a84f00 | 制作中のみ：仮置き原稿／要確認 |

コントラスト（`--c-paper` 上）：本文 ≒ 16:1、補足 ≒ 6.8:1、キャプション ≒ 5:1、`--c-accent` ≒ 6.6:1、白文字 on `--c-accent` ≒ 7.3:1（いずれも WCAG AA 以上）。

### 文字

| 用途 | 書体 | サイズ（トークン） |
|---|---|---|
| 見出し・章の問い・数字 | Noto Serif JP（明朝） | `--fs-num`（章番号 64–144px）／`--fs-2xl`（30–52）／`--fs-xl`（24–36）／`--fs-lg`（20–24） |
| 本文・UI | Noto Sans JP（ゴシック） | `--fs-md` 18／`--fs-base` 16／`--fs-sm` 14／`--fs-xs` 12 |

- 本文：行間 1.95、字間 0.04em、1行の最大幅 40em（`--w-text`）
- 英字ラベル（`.label`）：12px・大文字・字間 0.2em。日本語見出しの「上」に小さく添える（主従を逆にしない）
- 縦書き・和柄は使わない（docs/00 §5）

### 余白・レイアウト

- 4 の倍数：`--sp-1`(4) 〜 `--sp-10`(128)
- セクション上下：`--section`（画面幅に応じて 64〜128px）
- 画面端：`--gutter`（16〜48px）、コンテンツ最大幅 1200px
- ブレークポイント：600 / 768 / 960（ナビ切替）/ 1024 / 1200

## 4. UX の決めごと

| 項目 | 決めごと |
|---|---|
| 読み進め方 | TOP の各章セクションは「問い → 要点 → 証拠（写真・事実）→ 章ページへ」の同じ型 |
| ナビの現在地 | 章ナビは `aria-current` で下線（アクセント色）。章番号はどこでも同じ順番 |
| 出現アニメーション | `data-reveal` で 16px のフェードイン。`prefers-reduced-motion` では無効 |
| FV | 写真3〜4枚の 6 秒クロスフェード（reduced-motion では1枚目のみ） |
| フォーム | 窓口を `?type=` で初期選択。取引相談だけ業態等の追加項目を表示。入力 → 確認 → 送信 → 完了。完了画面から「01 理念」へ |
| アクセシビリティ | スキップリンク／フォーカスリング（アクセント色 2px）／画像の代替テキストは CMS で入力／タップ領域 44px 以上 |
| 制作中の表示 | 【仮置き】は青い破線、要確認はオレンジのバッジ。原稿差し替えで自然に消える |
