# ⑤ 写真・素材リスト

## 撮影の共通方針

- **主役は「人の手」と「使われている場面」**。食材だけの物撮りは補助的に
- **沖縄らしさは記号ではなく現場から**。海・シーサー・赤瓦・ビーチは使わない。県内の厨房、食堂、市場、生産者、繁忙期の倉庫、夏の強い光、台風前の慌ただしさなど、沖縄の食の営みの中で自然に写り込むものを撮る
- **実際の業務時間に撮る**。早朝の出荷・昼の店舗・夕方の仕込みなど、時間帯の違う光を集める
- **演出しすぎない**。笑顔の作り込みより、仕事に集中している表情を優先
- **取引先・生産者の撮影は事前に掲載許諾を取る**
