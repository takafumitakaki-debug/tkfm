# 00. 設計の前提と全体方針

株式会社イバノ コーポレートサイト リニューアル ／ 情報設計・ワイヤーフレーム

---

## 1. このサイトの主役

主役は「事業内容」ではなく **イバノという会社そのもの**。

一般的な食品卸のサイト：

```
食品を扱っています → こんなサービスがあります → 会社概要
```

今回のサイト：

```
理念 → フィロソフィ → 事業 → 人 → 地域
（なぜ）  （どう考えて）  （何で）  （誰が）  （何が生まれているか）
```

この5つを **「5つの章」** として扱い、サイト全体を1冊の本のように読める構造にする。

| 章 | ページ | 答える問い |
|---|---|---|
| 01 | 理念（ABOUT） | なぜイバノはこの会社を続けているのか |
| 02 | フィロソフィ（PHILOSOPHY） | その理念を、日々の仕事でどう形にしているのか |
| 03 | 事業（BUSINESS） | 理念とフィロソフィを、実際の仕事としてどう実現しているのか |
| 04 | 人（PEOPLE） | イバノを支えているのは誰なのか |
| 05 | 地域（AREA） | イバノは沖縄の食と地域にどう関わっているのか |

### 章構造を成立させる3つの仕掛け

1. **章番号を全ページで共通化**
   グローバルナビ・TOP・下層ページすべてで「01 理念」〜「05 地域」の番号と順番を固定する。ユーザーがどこにいても「今、物語のどこを読んでいるか」が分かる。
2. **各下層ページの最後に「次の章へ」**
   理念ページの最後はフィロソフィへ、フィロソフィの最後は事業へ…と、ページ末尾で必ず次の章に送る。05 地域の最後は「採用」と「お問い合わせ」に着地させる。
3. **「理念とのつながり」を各コンテンツに明記**
   事業紹介・社員インタビュー・地域の取り組みには、必ず「このコンテンツはどのフィロソフィ項目とつながっているか」を示すタグ（例：`フィロソフィ 03 と関連`）を付ける。正式なフィロソフィ原稿が入った時点で紐付けを確定する。

## 2. 「沖縄の食を支える」の扱い方

コピーとして連呼しない。**各章が、この言葉の一部分ずつを証明する** 構造にする。

| 問い | 答える章 | 証明の手段 |
|---|---|---|
| なぜ沖縄の食を支えるのか | 01 理念 | 経営理念・代表メッセージ・1963年からの経緯 |
| どんな考え方で支えているのか | 02 フィロソフィ | 仕事の判断基準・お客様／商品／社員への考え方 |
| どんな事業で支えているのか | 03 事業 | 卸・輸入・店舗・PB／取引先の業態／食材が届くまでの流れ |
| 誰が支えているのか | 04 人 | 営業・配送・倉庫・店舗スタッフの顔と言葉 |
| 地域にどんな価値を生んでいるのか | 05 地域 | 取引先・生産者・地域行事・浦添との関係 |

### 使用ルール

- 「沖縄の食を支える」という言葉そのものは **TOPのファーストビュー付近と、05 地域の結び** の2か所程度に絞る。
- それ以外の場所では、言葉ではなく **具体的な事実（取引先の業態、食材名、場面、数字）** で語る。

## 4. コピーの方針

### 使わない表現

どの会社にも当てはまる抽象語は使わない。

- 未来を創造する／新たな価値を提供する／可能性を広げる／人と食をつなぐ
- 笑顔あふれる／豊かな食文化の発展に貢献／お客様第一／挑戦し続ける
- 「〜に寄り添う」「〜を彩る」「〜の架け橋」

### 優先する表現

イバノだから成立する言葉を優先する。言葉の素材は **固有名詞・年号・場面・数字・社員本人の言葉**。

| NG（抽象） | OK の方向性（具体） |
|---|---|
| 沖縄の食文化に貢献しています | 県内のホテルの朝食、居酒屋のつまみ、家庭の焼肉。そのどれかに、イバノの肉が使われています。（※事実確認後） |
| 高品質な食材をお届けします | どの国の、どの部位を、どういう基準で選んでいるか |
| 社員を大切にしています | 社長が一人ひとりに書く誕生日カード（※事実確認後） |

### 仮置きのルール

正式原稿がない箇所は **創作しない**。以下の表記で仮置きする。

- `【経営理念原稿を配置】`
- `【フィロソフィ原稿を配置】`
- `【代表メッセージ原稿を配置】`
- `【◯◯の数値を確認して配置】`

ワイヤー内で「コピー案」として例を示す場合は、必ず **（コピー案・要協議）** と明記し、公開情報の事実に基づくものに限定する。

## 5. デザインの方向性（ワイヤー段階での意図）

完成デザインではないが、以下の思想が構造から感じられるようにする。

| 方向性 | 構造・ワイヤーでの表現 |
|---|---|
| 食品会社らしい温かみ | 商品の物撮りではなく「人の手」と「使われている場面」の写真を主にする |
| 沖縄らしさ | 海・シーサー・赤瓦など記号的な沖縄は使わない。県内のホテルの厨房、食堂、市場、行事前の繁忙、台風前の配送など **沖縄の食の営みの現場** から沖縄を感じさせる |
| 信頼感 | 情報は整理された余白の中に置く。数字・沿革・会社概要は表組みで明快に |
| 歴史と積み重ね | 1963年からの年表を ABOUT のストーリーと COMPANY の資料の2層で扱う。古い写真が残っていれば積極的に使う |
| 人の温度感 | 社員の名前・顔・本人の言葉を全章に登場させる（事業ページにも担当者の言葉を置く） |
| 地域とのつながり | 05 地域を「CSR」ではなく、01〜04 の結果として置く |
| 古すぎない／観光サイトにしない／卸会社のテンプレにしない | 縦書きや和柄に頼らない。商品カタログ型のグリッドを TOP に置かない。章番号を使った編集的なレイアウト |

### 写真トーン（撮影ディレクション共通）

- 演出しすぎない。実際の業務時間帯に撮る（早朝の出荷、昼の店舗、夕方の仕込み）
- 社員は「カメラ目線の集合写真」より「仕事中の横顔・手元」を主に、ポートレートは各インタビューに1枚
- 食材は「パッケージ」より「カットされた断面・厨房で使われる瞬間」
