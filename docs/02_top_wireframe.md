# ② TOPページ 詳細ワイヤーフレーム

ビジュアル版：`wireframes/index.html`

## TOP の設計意図

TOPだけを読み通しても「イバノは何を大切にしている会社か」が分かるように、**01〜05 の章を、それぞれの章ページの「予告編」として並べる**。

- 各章セクションは「問い（その章が答える問い）→ 要点 → 証拠（写真・事実）→ 章ページへ」の同じ型で揃える
- 章ごとに写真の主役を変える：01＝創業の記録、02＝仕事中の手元、03＝食材が届く現場、04＝社員の顔、05＝取引先・地域の現場
- 事業の商品グリッドや「サービス一覧」は TOP に置かない

```
┌──────────────────────────────┐
│ HEADER                        │
├──────────────────────────────┤
│ S00 ファーストビュー            │
│ S01 理念         ── 01         │
│ S02 フィロソフィ   ── 02         │
│ S03 事業         ── 03         │
│ S04 人           ── 04         │
│ S05 地域         ── 05         │
│ S06 ニュース                    │
│ S07 採用                        │
│ S08 会社情報                    │
│ S09 お問い合わせ                 │
├──────────────────────────────┤
│ FOOTER                        │
└──────────────────────────────┘
```

## S03 事業 ── 03

| 項目 | 内容 |
|---|---|

| ユーザーに理解してほしいこと | イバノの食材は、ホテルの朝食・レストラン・居酒屋・家庭の食卓という沖縄の食のさまざまな場面に届いている。そしてそれは世界から食材を選んで運ぶ仕事によって成り立っている |
| 見出し | 章ラベル：`03 事業 / BUSINESS`<br>問い：「その考え方を、どんな仕事で実現しているのか。」 |
| 説明文 | リード：【事業全体を説明する原稿を配置（理念とのつながりを1文入れる）】<br><br>**図解：食材が沖縄の食卓に届くまで**<br>`世界・県内の生産者 → 調達・輸入 → 保管・加工 → 営業・提案 → 配送 → ホテル／飲食店／家庭`<br><br>**4つの事業カード**（「誰に」を見出しにする）<br>① ホテル・レストラン・居酒屋へ ― 業務用食材の卸販売<br>② 世界と県内の食材を、沖縄へ ― 国内外の食材の調達・輸入<br>③ 家庭の食卓へ ― イバノ牧港店／IVANO SELECT<br>④ イバノにしかない商品を ― 自社PB商品の開発<br><br>**数字で見るイバノ**（4つまで）<br>創業 1963年／社員数 147名（要確認）／取引先数 【要確認】／取扱国 【要確認：IVANO SELECTは35か国】 |
