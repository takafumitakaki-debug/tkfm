# TKFM 動画エディタ

ブラウザだけで動く動画編集ソフト。ビルド・インストール不要で、素材ファイルは外部に送信されず手元のブラウザ内で処理される。

## 起動

`video-editor/index.html` を Chrome または Edge で開く（ダブルクリックでも動く）。
フォント（Google Fonts）の読み込みにだけインターネット接続を使う。

## できること

| 分類 | 機能 |
|---|---|
| 素材 | 動画・画像・音声の読み込み（ボタン／ドラッグ＆ドロップ）、サムネイル・波形表示 |
| 映像トラック | 前詰め配置、ドラッグで並べ替え、端のドラッグでトリム、分割、複製、削除 |
| クリップ設定 | 使用範囲、速度（0.25〜4倍）、音量（0〜200%）、フェードイン／アウト、明るさ・コントラスト・彩度、フィット（全体／画面を埋める／引き伸ばし）、静止画のゆっくりズーム |
| テキスト | 字幕・テロップ（フォント5種、サイズ、色、太字、縁取り、背景帯）、位置（プレビュー上でドラッグ可）、アニメ（スライド／ズーム／タイプライター）、フェード |
| 音声トラック | BGM・効果音の自由配置、トリム、音量、フェード（動画ファイルを置くとその音声だけ使える） |
| タイムライン | ズーム（Ctrl＋ホイール）、全体表示、スナップ（再生ヘッド・クリップ端）、スクラブ |
| 出力 | MP4（ブラウザ対応時）／WebM 書き出し、解像度（横・縦型・正方形・4K）、fps、画質、現フレームの PNG 保存 |
| その他 | 元に戻す／やり直し、プロジェクト保存・読み込み（JSON） |

## ショートカット

| キー | 操作 |
|---|---|
| Space | 再生／一時停止 |
| S | 再生ヘッドで分割（選択中クリップ優先） |
| T | テキスト追加 |
| Delete / Backspace | 選択クリップを削除 |
| ← / → | 1フレーム移動（Shift で 1 秒） |
| Home / End | 先頭／末尾へ |
| Ctrl+D | 複製 |
| Ctrl+Z / Ctrl+Y（Ctrl+Shift+Z） | 元に戻す／やり直し |
| Ctrl+S | プロジェクト保存 |
| + / − | タイムライン拡大／縮小 |

## 注意・制約

- **書き出しは実時間**：タイムラインを再生しながら録画するため、10分の動画は約10分かかる。書き出し中はタブを前面に表示しておくこと（裏に回すと描画が止まる）。
- **MP4 書き出し**は Chrome / Edge の比較的新しい版で使える。使えない環境では WebM になる。WebM はシーク情報が入らないため、一部のプレイヤーでシークバーが効かないことがある。
- **プロジェクトファイル（.json）に素材本体は含まれない**。開いたあと同じ名前の素材ファイルを読み込むと自動で再リンクされる。
- 再生できる形式はブラウザ依存（H.264 MP4・WebM・MP3・AAC・WAV などは Chrome で可。HEVC/ProRes の MOV は環境によって不可）。

## 構成

| ファイル | 役割 |
|---|---|
| `index.html` / `style.css` | 画面 |
| `js/util.js` | 共通関数・イベントバス |
| `js/project.js` | プロジェクト状態、履歴（Undo/Redo）、編集操作、保存・読み込み |
| `js/media.js` | 素材の読み込み（メタデータ・サムネイル・波形） |
| `js/engine.js` | 再生・合成エンジン（canvas 描画、WebAudio ミックス、同期） |
| `js/timeline.js` | タイムライン UI（移動・トリム・並べ替え・シーク・ドロップ） |
| `js/panels.js` | 素材ビン、プロパティパネル |
| `js/exporter.js` | 書き出し（canvas＋音声ストリームを MediaRecorder で録画） |
| `js/main.js` | 画面の組み立て、ボタン、キーボードショートカット |
