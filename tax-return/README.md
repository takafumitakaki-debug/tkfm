# 確定申告ナビ（会社員＋副業・控除）

会社員が副業所得・医療費控除・ふるさと納税などで確定申告するときの補助ツール。ブラウザだけで動き、ビルドやインストールは要らない。入力したデータは手元のブラウザ（localStorage）の中だけに保存され、外部には送られない。

## 起動

`tax-return/index.html` をブラウザで開く（ダブルクリックでも動く）。スマートフォンの画面幅にも対応している。

## できること

| タブ | 内容 |
|---|---|
| ① 源泉徴収票 | 支払金額・源泉徴収税額・社会保険料・各控除額を写す。2か所以上の給与（年末調整済み／未）にも対応。給与所得は自動で計算し、源泉徴収票の値と照合できる |
| ② 副業の帳簿 | 収入・経費の記録（科目、家事按分、源泉徴収額。10.21% の自動計算あり）。銀行・カード明細の CSV 取り込みに対応（列の対応づけ、Shift_JIS/UTF-8 の自動判定、摘要からの科目推定）。科目別の集計、CSV 書き出し。雑所得（業務）と事業所得（青色申告特別控除）を選べる |
| ③ 控除 | 医療費控除（補填額、足切りの計算）とセルフメディケーション税制のどちらが有利かの判定、ふるさと納税（寄附金控除と上限の目安）、年末調整に含まれていない社会保険料・iDeCo・保険料、扶養・障害者・ひとり親など |
| ④ 計算結果 | 申告が必要かどうか（副業20万円ルール、2か所給与など）、所得・所得控除・所得税・復興特別所得税、還付額または納付額、住民税の概算 |
| ⑤ 転記ガイド | 申告書 第一表の各欄に入る金額（クリックするとコピーできる）、第二表「所得の内訳」、経費の内訳、確定申告書等作成コーナーでの手順 |
| ⑥ 書類チェック | 入力内容に応じて、集める書類のチェックリストと申告スケジュールを出す |

画面上部のバーには、還付または納付の見込み額が常に表示される。「バックアップ」で全データを JSON に保存し、「復元」で読み込める（別の端末への移行にも使える）。「印刷」は計算結果と転記ガイドを印刷する。

## 対応する年分と税制

| 年分 | 反映した内容 |
|---|---|
| 令和7年分（2025年） | 基礎控除 58万円＋所得に応じた上乗せ（最大95万円）、給与所得控除の最低保障 65万円（いわゆる160万円の壁） |
| 令和8年分（2026年） | 基礎控除 本則62万円＋特例（合計所得489万円以下で104万円、655万円以下で67万円）、給与所得控除の最低保障 74万円（いわゆる178万円の壁） |

年分ごとの数値は `js/rules.js` にまとめてある。令和8年分の数値は改正の解説資料から入れたもので、国税庁の確定版の表・様式で確認すること。

## 計算の範囲と注意

- 対象は「給与＋副業（雑所得・事業所得）＋一般的な所得控除」。不動産所得・株式・譲渡所得・公的年金、雑損控除、外国税額控除、住宅ローン控除の1年目、損失の繰越しなどは扱わない。
- 配偶者（特別）控除・生命保険料控除・地震保険料控除・住宅ローン控除（2年目以降）は、源泉徴収票の金額をそのまま使う。
- 住民税は、人的控除の差・保険料控除を簡単な換算で近似した**概算**。ふるさと納税の上限も目安。
- 申告書の欄の番号は様式の改定で変わるため、転記ガイドでは欄の名前で示している。
- 最終的な金額は国税庁「確定申告書等作成コーナー」の計算結果で確認すること。

## 構成

| ファイル | 役割 |
|---|---|
| `index.html` / `style.css` | 画面（ライト／ダーク対応、印刷用レイアウト） |
| `js/rules.js` | 年分ごとの税制パラメータ、速算表、人的控除、勘定科目、CSV の自動仕分けルール |
| `js/calc.js` | 税額計算（DOM に依存しない純粋関数） |
| `js/store.js` | 保存・バックアップ、CSV の読み書き |
| `js/app.js` | 各タブの画面、入力、再計算 |
| `test/calc.test.js` | 計算のテスト（`node --test tax-return/test/*.test.js`） |
