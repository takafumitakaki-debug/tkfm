# こども積立 勝率ナビ

子どもの教育資金を毎月つみたてた場合に、1970〜2025年の実際の値動きで「何回中何回は元本割れしなかったか（勝率）」を商品タイプごとに比べるツール。

`index.html` をブラウザで開くだけで動く（ビルド不要・外部通信はGoogle Fontsのみ）。データは同じフォルダの `data.js` から読む。

## 毎日の自動更新

`.github/workflows/kodomo-shoritsu-data.yml` が毎朝7:23（日本時間）に `scripts/update_data.py` を実行し、変化があればコミットする。

- 取得元：FRED（米セントルイス連銀）の公開CSV。S&P500（`SP500`）・日経平均（`NIKKEI225`）・ドル円（`DEXJPUS`）の日次終値。APIキー不要
- 今年の年初来の動きを `data.js` に書き出し、画面上部の「いまの市場」に表示する
- 年が明けて前年の年末値が3系列ともそろうと、前年分を `data/history.json` に追加し、勝率の計算に加える。自動で加わる年の米国株は「値上がり率＋配当1.3%」、預金金利は `default_dep_pct`（初期値0.3%）を使う
- 取得に失敗した日はデータを変えずにActionsが失敗表示になる
- 手で動かすとき：GitHubの Actions タブ →「こども積立 勝率ナビ データ更新」→ Run workflow。ローカルでは `python kodomo-shoritsu/scripts/update_data.py`
- 預金金利を見直すときは `data/history.json` の `default_dep_pct` や各年の `dep` を書き換える

## できること

- お子さんの年齢・つみたて年数・毎月の金額を入力
- 米国株／日米株半々／日本株／株式半分＋預金半分／預金のみ の勝率、最悪・中央値・最良の結果を表示
- 始めた年ごとの結果を棒グラフで表示（元本割れした年が赤）
- つみたて年数（3〜20年）ごとの勝率表

## 前提と注意

- 「絶対に損しない」投資はない。表示するのは過去データでの勝率で、将来を保証しない。
- ジュニアNISAは2023年末で新規買付終了。2027年から18歳未満もつみたて投資枠を使える制度（こども支援NISA）が始まる見込み。条件は金融庁の最新情報で確認すること。
- 1970〜2025年のデータは年次の概算：S&P500配当込みリターン（年末ドル円で円換算）、日経平均年末値＋配当1.7%/年、1年定期の概算金利。手数料・税金・インフレは含まない。
- 期間は1年ずつずらして重ねているため、各期間は独立した試行ではない。
- 教育目的の参考値であり、特定の金融商品の購入を勧めるものではない。
